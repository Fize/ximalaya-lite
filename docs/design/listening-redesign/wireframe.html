状态与恢复规则
组件状态规范
列表 / 搜索正常展示缓存；初次加载骨架；空态给搜索或发现入口；请求失败保留旧内容，首次失败显示重试；分页失败只重试下一页。长标题换行，不挤压触点。
下拉刷新仅列表顶部可触发；拉动 72 px 松手刷新，180 px 封顶；进行中忽略重复手势；成功轻提示；失败不清内容。辅助技术提供“刷新列表”自定义操作，键盘演示 Alt+R。
播放 / 权益默认显示播放；请求中当前行加载并禁重复；切集使旧结果失效；成功开始播放且不抢页面；失败当前行显示原因与重试；无权益提示“本集暂不可收听”，无购买按钮；失效提供“重新登录”。
订阅未订阅 / 已订阅；提交中禁重复；失败恢复原状态并提示；离线不假报成功。退出账号不删本机记录。取消订阅不删历史。
播放控制暂停 / 播放状态一致；无时长时进度禁用；到开头 / 末尾不越界；缓冲显示当前节目加载，用户暂停优先；无可播放队列时禁用。
按钮 / 筛选 / 输入正常 / hover 灰底 / focus 可见描边 / active 压下 / disabled 降低强调且不响应；选中标签保留文字标记。搜索空白禁提交，回车提交，失败保留关键词。
弹层仅用户打开队列、倍速、定时、选集或处理登录时出现；焦点限制层内，关闭返回原触发点；返回先关层再退页。授权成功不弹层。

线框演示上述主状态；真实断网、权限、音频、TalkBack 和持久化将在 Android 实施后测试，不能以原型通过替代。

范围与设计依据

依据：用户反馈（授权弹窗、重复刷新按钮、解释性文案）；可用性原则（系统状态可见、用户控制、识别优于回忆）；Android MD3 既有组件。后台继续做每集真实授权，不因隐藏弹窗跳过授权。

小宇宙产品页：发现、搜索、收听记录构成内容主线；借鉴聚焦内容的组织方式，不照搬评论、社交与独有数据。Apple 播客播放说明：播放页管理待播队列；保留集中控制，不沿用原首页横向分组堆叠。喜马拉雅产品页：长篇有声内容多；保留专辑选集及权益，排除营销和付费入口。

研究基于官方公开产品资料，未声称实际操作了这三款 App 的最新客户端。以上借鉴为设计推导，不是用户研究实测结论。

不新增评论、社交、推荐算法、下载、支付、充值或打赏。不重写已验证的播放与账号服务。订阅更新流缺少聚合接口依据，因此首页先使用已存在的最近收听和订阅专辑。

未选方案：照搬小宇宙全部导航会丢失长篇选集需求；沿用原多组横滑会让继续播放不突出；常驻解释同步机制会打断找内容。
