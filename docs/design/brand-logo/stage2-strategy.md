# Brand Strategy: 拾昔

## Stage Progress
- Current stage: 2
- Previous gate passed: stage1-research.md 的功能依据、竞争对照和触点范围已完成。
- Next gate to pass: 用户确认核心概念与性格关键词后进入 2–3 个视觉方向探索。

## Strategic Foundation
- Core concept: 用一个简洁符号表达轻量化听书与节目收听，传递故事陪伴。此句为内部设计策略，不是品牌口号。
- Brand personality: 专注、温暖、可靠、轻盈。
- Competitive gap identified: 聚焦听书、节目与故事陪伴，区别于行星探索、听字平台标识及紫色传播环。

## Deliverables This Stage
- 视觉策略：现代、有人情味、简洁、偏沉稳；符号优先表达“听与接续”的关系，避免把多个功能图标堆在一起。现有名称“拾昔”作为产品事实使用，本轮不产生新名称、口号或产品文案。
- 色彩角色：沿用应用已确认的克制橙 #BC451D 作为识别主色，暖白 #FCFCFB 留白，墨色 #252925 用于品牌名称；深色环境使用现有浅橙 #F29466。橙色用于识别与关键操作，不能扩散为全文颜色。
- 探索验收：之后提供 2–3 个真正不同的造型方向，每个说明隐喻、记忆点与误读风险；在 Android 自适应蒙版、24/48/96 dp、浅深色和单色中比较，再由用户选定。不得把策略批准当作造型批准。
- 对比度实算（WCAG 相对亮度公式）：
  - #BC451D / #FFFFFF: 5.24:1。
  - #BC451D / #FCFCFB: 5.1:1。
  - #F29466 / #171B18: 7.63:1。
  - #252925 / #FCFCFB: 14.38:1。

  上述色对均超过普通文字 AA 的 4.5:1；Logo 本身不按正文文字要求判定，但配套文字及功能用色仍采用此标准。最终候选造型仍须验证实际渲染、尺寸与蒙版。

## Rationale Log
| Decision | Strategic Basis | Alternatives Considered |
|----------|-----------------|------------------------|
| 采用轻量收听与故事陪伴为核心 | 用户本轮明确要求更突出听书与故事陪伴，并进一步指定“简化版的喜马拉雅”定位 | “内容发现”较弱化日常继续收听；“怀旧”无已验证功能支撑 |
| 沿用克制橙 | 用户此前明确选择，且已有应用视觉系统 | 新增蓝紫会接近竞品并造成现有界面割裂 |
| 单色也必须可识别 | Android 主题图标及小尺寸触点 | 依赖渐变和微小细节的造型不适合作为核心标志 |
